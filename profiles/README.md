# 群友资料

每位群友有一份独立的 Markdown 文件。文件名是三位编号，例如 `001.md`。从群友主页点「编辑签名和头像」可以打开对应文件，首次填写时会自动带上模板。

```markdown
# 群友 001

周末一起去打羽毛球吧。

![头像](avatars/001.png)
```

正文是个性签名，可以换行，最多 280 个字符，页面按文本显示。签名和头像都可以单独修改。删除签名正文即可清空签名，删除图片行即可恢复原头像。

更换头像时，把图片提交到同一分支的 `profiles/avatars/` 目录，用自己的三位编号命名。支持 PNG、JPEG 和 WebP，单张最多 2 MiB。在 Markdown 里添加对应的图片行，再把图片和 Markdown 放进同一个 PR。新头像和签名会公开在 GitHub 仓库及其历史中。

向 `main` 发 PR，维护者核对群友编号、提交者和内容后合并。网站会自动读取已合并的资料。
